# チーム野球ノート

少年野球の親のための、試合記録・選手カルテ・フォーム確認アプリです。
ログインは不要です。データは使う人のスマホのブラウザの中だけに保存されます。

## 入っているファイル

| ファイル | 役割 |
|---|---|
| index.html | アプリ本体（画面もプログラムもこの1つに入っています） |
| sw.js | 電波がなくても開けるようにするための仕組み |
| manifest.webmanifest | ホーム画面に追加したときの名前やアイコン |
| icon-192.png / icon-512.png | アイコン |

5つとも、同じ場所（同じフォルダ）に置いてください。

## GitHub Pages で公開する手順（無料）

1. GitHub のアカウントを作り、右上の「+」→「New repository」で新しいリポジトリを作ります（例：baseball-note、Public を選ぶ）。
2. リポジトリの画面で「Add file」→「Upload files」を押し、5つのファイルをまとめてドラッグして「Commit changes」を押します。
3. 「Settings」→ 左の「Pages」を開き、Branch を「main」、フォルダを「/ (root)」にして「Save」を押します。
4. 1〜2分待つと、`https://（ユーザー名）.github.io/baseball-note/` で開けるようになります。このURLを利用者に配ってください。

## アプリを更新するとき

1. 新しい index.html を同じようにアップロードして上書きします。
2. sw.js の `const VERSION = 'v1';` の数字を1つ上げて（v2 など）、sw.js もアップロードします。
   こうすると、利用者のスマホでも次に開いたときに新しい版に切り替わります。

利用者のデータはスマホの中にあるので、アプリを更新しても消えません。

## 利用者に伝えておくこと

- 記録はそのスマホのブラウザの中だけにあります。ブラウザのデータを消す・機種変更する前に、「名簿・設定」→「バックアップファイルを保存」をしてください。
- iPhone は Safari で開き、共有ボタン →「ホーム画面に追加」すると、アプリのように使え、電波のないグラウンドでも開けます。Android は Chrome のメニュー →「ホーム画面に追加」。
- 別の保護者に名簿や記録を渡すときは、バックアップファイルを送り、相手が「バックアップファイルから読み込む」を押します。
- 「紙のスコアを取り込む」（写真から読み取る機能）は、このアプリを claude.ai の中で開いたときだけ表示されます。自分のサイトで公開した版では表示されません。
