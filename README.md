# ShotFind

チームの試合写真から、わが子の写真を探す。

少年野球・中学野球の親のための無料ツールです。LINEアルバムなどから保存した何百枚の試合写真の中から、わが子が写っている写真だけをAIで探し、そのまま家族のLINEに送れます。

**使う：** https://yatti3g-byte.github.io/ShotFind/
**使い方・Q&A：** https://yatti3g-byte.github.io/ShotFind/help.html

## できること

- わが子の顔写真を3〜10枚選ぶだけで、試合写真の中から顔で照合して探す
- 結果を「見つかった写真」「確認をおすすめ」「顔を検出できなかった写真」に分けて表示
- 写真を大きく表示して確かめ、選んだ写真を共有メニューからLINEなどに送る
- 一致度（目安）を変えても写真を調べ直さないので、すぐ切り替わる
- 顔の特徴を端末に保存して、次回も選び直さずに使える（任意・初期設定はオフ）
- サンプルの絵を使った1分のチュートリアル

登録なし・無料・広告なし。スマホのブラウザで開くだけで使えます。

## データの扱い

**どこで処理するか**
顔の照合は、すべてこの端末のブラウザの中で行います。写真はアップロードしません。

**この端末に保存するもの**
- 写真と探した結果は保存しません。ページを閉じると消えます。
- 「この端末に顔の特徴を保存」をオンにしたときだけ、照合用の顔の特徴データと、確認用の小さな顔の画像を、ブラウザに保存します。「保存した顔を消す」か、ブラウザの閲覧データを消すと削除されます。
- ほかに保存するのは、チュートリアルを見たかどうかだけです。

**外と通信するとき**
- ページを開いたとき、顔を照合するAIのプログラムとモデル（数MB）を、公開の配信サービス（jsDelivr）から読み込みます。写真はこのとき送りません。
- 選んだ写真を共有したときは、自分が選んだ相手に写真が渡ります。

## しくみ

- 1つのHTMLファイルで動く静的なWebアプリです（GitHub Pagesで公開）。
- 顔の検出と照合には、ブラウザで動くオープンソースのライブラリ [Human](https://github.com/vladmandic/human)（3.3.6）を使っています。

## 試作版について

帽子やヘルメットで顔が隠れた写真、横顔、遠くて顔が小さい写真は見落とすことがあります。結果の「確認をおすすめ」と「顔を検出できなかった写真」もあわせて見てください。

## DugoutTools

ShotFindは、少年野球の現場で使える、無料・登録なしの道具「DugoutTools」のひとつです。

- [TapScore](https://yatti3g-byte.github.io/TapScore/)：1球ずつタップして記録するスコアブック
- [PitchCount](https://yatti3g-byte.github.io/PitchCount/)：球数制限に合わせた球数カウンター
- [FormNote](https://yatti3g-byte.github.io/form-note/)：コマ送りと角度の測定で、フォームを確認
- **ShotFind**：チームの試合写真から、わが子の写真を探す
